# NovaPulse - Modern Responsive SaaS Landing Page

A clean, modern, and fully responsive landing page built with **HTML5**, **CSS3**, and lightweight **JavaScript**. Designed for an AI-powered workflow automation platform (NovaPulse), this project demonstrates modern front-end layout techniques, mobile-first responsiveness, and smooth UI interactivity.

## ✨ Features

* **Fully Responsive Design:** Adapts smoothly across mobile phones, tablets, and large desktop screens using fluid layouts and CSS media queries.
* **Interactive Navigation (JS):** 
  * **Dynamic Header Scroll Effect:** Automatically shifts background opacity, border styling, and adds a drop-shadow as the user scrolls down the page.
  * **Smooth Link Micro-interactions:** Enhances menu hover states with subtle elevation and color transitions.
* **Modern Architecture:** Utilizes CSS Custom Variables (`:root`), Flexbox, CSS Grid, and vanilla JavaScript event listeners without heavy external frameworks.
* **Pre-built Sections:** Includes a navigation header, hero section with a visual dashboard preview, social proof logos, feature cards, tiered pricing table, call-to-action banner, and footer.

---

## 🛠️ Tech Stack

* **Markup:** HTML5
* **Styling:** CSS3 (Custom properties, Flexbox, Grid, transitions)
* **Scripting:** Vanilla JavaScript (DOM manipulation & scroll event listeners)
* **Typography:** [Plus Jakarta Sans](https://fonts.google.com/specimen/Plus+Jakarta+Sans) (Google Fonts)
* **Icons:** Inline SVG graphics
