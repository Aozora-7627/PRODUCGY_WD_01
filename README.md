# NovaPulse - Modern Responsive SaaS Landing Page

A clean, modern, and fully responsive landing page built with pure **HTML5** and **CSS3**. Designed for an AI-powered workflow automation platform (NovaPulse), this project demonstrates modern front-end layout techniques, mobile-first responsiveness, and sleek UI design without the need for any external frameworks or JavaScript.

## ✨ Features

* **Fully Responsive Design:** Adapts smoothly across mobile phones, tablets, and large desktop screens using fluid layouts and CSS media queries.
* **Pure HTML & CSS:** Zero JavaScript dependencies required, ensuring fast load times and lightweight performance.
* **Modern CSS Architecture:** Utilizes CSS Custom Variables (`:root`), Flexbox, and CSS Grid for clean, maintainable styling.
* **Interactive Polish:** Smooth scrolling behavior (`scroll-behavior: smooth`) and subtle hover transition effects.
* **Pre-built Sections:** Includes a navigation header, hero section with a visual dashboard preview, social proof logos, feature cards, tiered pricing table, call-to-action banner, and footer.

---

## 🛠️ Tech Stack

* **Markup:** HTML5
* **Styling:** CSS3 (Custom properties, Flexbox, Grid)
* **Typography:** [Plus Jakarta Sans](https://fonts.google.com/specimen/Plus+Jakarta+Sans) (Google Fonts)
* **Icons:** Inline SVG graphics
